# TrailMap 🗺️🥾

**TrailMap** è un'applicazione web interattiva per l'esplorazione, la pianificazione e la visualizzazione altimetrica di sentieri da trekking, trail running e mountain bike.

## Funzionalità
- 🗺️ **Mappa Interattiva Leaflet**: Visualizzazione tracciati con cartografia topo/outdoor.
- 📈 **Profilo Altimetrico**: Grafico altimetrico in tempo reale (Chart.js) sincronizzato con i dati del sentiero.
- 🔍 **Ricerca & Filtri**: Filtra i sentieri per nome, regione o livello di difficoltà (Facile, Medio, Difficile, Esperto).
- 📁 **Supporto GPX**: Inizializzato per import/export di tracce GPS standard `.gpx`.

## Avvio Locale
```bash
# Avvio server di sviluppo (Node / Vite)
npm run dev

# Oppure con Python
python3 -m http.server 3000
```
